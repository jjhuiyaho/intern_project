1. `image` 폴더에 사진 캡쳐본 넣어두기
2. 텍스트 파일 작성하고 싶은 폴더 내에서 파일명.md처럼 확장자가 .md(마크다운)인 파일 만들기
3. Edit 창에서 `![image.png](../image/사진파일명.png)`의 형태로 텍스트 입력하면 보임!! + 해당 창에서 메모장처럼 그냥 작성하고 Commit 버튼 누르면 지금 이런 식으로 텍스트도 작성할 수 있음!

추가적으로 수식이나 기호, 코드 추가 같은 내용 작성하고 싶으면 구글에 마크다운 문법 검색해서 사용하면 됨!
생각보다 자주 쓰는거 간단히 외워두면 지피티한테 물어보기도 편함~ 간단히 공부하면 어떤 내용이던 컴퓨터로도 문서 작업 가능!!
