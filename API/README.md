# (1팀) KOSIS 메타데이터 기반 통계 AI 가드레일 도입 제안
> **국가데이터처 청년인턴 정책제안 프로젝트 결과 보고서**

본 저장소는 국가 통계 API 파편화 및 AI 활용 인프라 부족 문제를 해결하고, 현행 대국민 통계 서비스의 신뢰성을 제고하기 위해 수행된 청년인턴 실증 과제물입니다.

KOSIS 공유서비스에서 제공하는 핵심 지표를 대상으로 비정형 서술형 통계 주석을 기계 판독이 가능한 구조화된 태그로 전환하여, 생성형 AI의 구조적 맥락맹(Context-Blindness) 현상과 수치 오독을 제어하는 가드레일 시스템 아키텍처를 실증하였습니다.

## 4. 데이터 수집 및 파이프라인 구축 방식

KOSIS에서 제공하는 두 가지 핵심 Open API 커넥터를 결합하여 데이터를 가공하였습니다.

1. **정형 수치 수집 (`statisticsData`):** 지표별 기계어 분류 코드와 통계 수치값을 매핑하여 시스템 콘텍스트의 기본 입력값으로 설정함.
2. **비정형 맥락 추출 (`statisticsExplData`):** 자연어 산문(줄글) 형태로 분리되어 존재하는 '유의사항' 및 '조사연혁' 필드를 파이썬 전처리 엔진으로 호출함.
3. **단편적 키워드 기반 태그 변환 (Metadata Assetization):** 파이썬 환경에서 [개편, 단절, 변경, 제외, 잠정] 등의 특정 핵심어를 검출하고, 이를 기계가 해독할 수 있는 고유 위험 태그(`warning_tags` : [시계열단절], [단순비교금지] 등) 및 논리적 근거(`evidence`) 구조를 가진 가드레일 JSON 미들웨어 파일로 자산화함.

## 5. 고성능 AI 모델에 '태그(가드레일)' 도입이 유용한 이유

최신 생성형 AI 모델의 뛰어난 언어 능력에도 불구하고, 국가 통계 데이터 연동 시 구조화된 메타데이터(가드레일)를 도입하는 것이 실유효한 이유는 다음과 같습니다.

- 명령 수행 편향 (착한 아이 콤플렉스): AI는 사용자의 명시적인 연산 요구(예: "두 수치를 비교해 줘")를 최우선 과제로 인식합니다. 통계 유의사항이 산문 형태로 첨부되어 있더라도 사용자의 계산 압박에 동조하여 수치 오독을 강행하는 경향이 관찰되었습니다.

- '참고 정보'와 '통제 규칙'의 인식 차이: 자연어 서술문은 AI에게 유연한 배경지식으로 취급되지만, 구조화된 태그([시계열단절] 등)는 시스템 프롬프트 단에서 준수해야 할 강제 행동 규칙으로 작동합니다.

- 확률적 추론의 일관성 보완: 확률 기반으로 대답을 생성하는 모델 특성상 동일한 질문에도 매번 다른 대답을 낼 위험이 있습니다. 대국민 서비스의 안전성을 확보하기 위해서는 위험 지표에 대한 연산 시도를 기계적으로 통제하는 미들웨어 장치가 유용합니다.

## 6. 4대 지표별 3단계 실증 실험 요약

본 실험은 AI의 연산 제어 역량을 확인하고자 총 3단계(1단계: 현행 코봇, 2단계: 메타데이터 미적용 상용 AI[Before], 3단계: 구조화 가드레일 적용 AI[After])의 대조군으로 설계되었습니다. AI가 데이터를 잘못 검색하는 오류를 배제하기 위해, 2단계와 3단계 프롬프트 내에 사용자가 정확한 수치를 직접 명시한 후 사칙연산을 요구하는 통제 환경을 구성했습니다.

* **경기종합지수 (담당: 한재희)**

* **비교 결과:** 2단계(Before)에서는 잠정치 경고 문구를 인지하고도 사용자의 연산 요구에 동조하여 과잉 해석을 강행하는 한계가 노출되었으나, 3단계(After)에서는 미들웨어 내 [잠정치포함] 및 [시계열단절] 태그 인식을 통해 연산을 차단하고 중장기 추세 분석 대안을 출력함 지표.

## 7. 단계별 종합 비교 및 향후 인프라 확장 제안

### 1) 데이터 연동 단계별 종합 비교

| 평가 항목 | 1단계: 현행 코봇 | 2단계: Before AI (산문형) | 3단계: After AI (구조화 가드레일) |
| --- | --- | --- | --- |
| **출처 및 수치 정확성** | 통계표 매핑 및 데이터 혼합 오류 | 산수는 일치하나 원천 수치 검증 불가 | 분석 전 출처 및 단위 일치 검증 수행 |
| **경고 신호 인지 능력** | 통계 제약 조건 인지 부재 | 자연어 서술 언급에 그침 | 구조화된 기계어 태그 즉각 인식 |
| **위험 감지 후 행동제어** | 환각 및 가상 수치 생성 | 사용자의 연산 요구에 동조 | 연산 기능 차단 및 조건부 허용 전환 |
| **종합 데이터 안전성** | **취약 (신뢰성 저하)** | **유의 요망 (오독 가능성)** | **안정적 (연산 통제 가능)** |

### 2) 현재 파이프라인의 한계 및 본 제안의 전략적 가치

- 단순 핵심어 매칭의 기술적 한계:
  현행 파이썬 기반 추출 방식은 특정 단어의 유무만 기계적으로 판단하므로, 유사 용어 간의 맥락적 차이를 해독하거나 지표 간의 복잡한 상하위 집합 관계(가산성 제약 등)를 온전히 반영하기 어렵습니다. 이로 인해 통계적 단절이 아님에도 위험으로 인지하는 오탐이나, 위험 신호를 놓치는 누락 리스크가 존재할 수 있습니다.

- 보수적 통제(안전 최우선) 설계를 통한 한계 돌파:
  완벽한 정밀도를 즉시 담보하기는 어려우나, 대국민 국가 통계 서비스의 특성상 '위험 신호를 놓치는 것(누락)'이 '과도하게 경고하는 것(오탐)'보다 훨씬 치명적입니다. 본 제안은 조금이라도 제약 조건이 의심될 경우 인공지능의 자의적 연산을 우선적으로 차단하는 '보수적 방어선'으로 설계되었습니다. 따라서 단편적 매칭의 한계에도 불구하고, 고위험 통계 환각을 시스템 차원에서 선제 방어하는 뚜렷한 실효성을 발휘합니다.

- 확장 가능한 토대(1차 방어선)로서의 가치:
  이상적인 대안인 '거대 통계 지식 체계' 구축에는 막대한 예산과 장기간의 공수가 소요됩니다. 본 제안은 단순한 임시방편이 아니라, 최소한의 공수로 즉시 도입 가능한 '1차 방어선(Baseline Safety Layer)'입니다. 또한 현재 구조화해 둔 태그 메타데이터는 향후 버려지는 것이 아니라, 고도화된 지식 체계를 구축할 때 핵심 기초 데이터로 호환 및 재활용될 수 있는 확장 가능한 토대입니다.

### 3) 향후 정책 발전 방향: '다층적 통계 지식 그래프(Knowledge Graph)' 기반 표준 모델 및 검증 체계 정립

상기 단편적 매핑의 한계를 보완하고 국가 통계 AI의 활용 인프라를 고도화하기 위해, 향후 국가데이터처의 'AI 친화적 통계 메타데이터 DB 구축 사업' 등 관련 과제 추진 시 **'한국표준산업분류(KSIC)' 등의 기보유 표준 코드 체계를 구조적 뼈대(Ontology)로 활용하는 '다층적 통계 지식 그래프' 인프라 구축**을 제안합니다.

아울러 본 인프라의 신뢰성을 완벽히 담보하기 위해 **'자동화와 전문 인력 간의 협업 체계(Human-in-the-Loop)'** 도입을 함께 제안합니다. 설명자료 API 문서를 LLM이 탐색하여 지식 맵과 상속 구조를 **자동으로 1차 생성**한 뒤, 통계 전문 인력이 핵심 제약 조건(가산성 상실, 분류 개편 등)을 **최종 검증 및 보완**하는 투트랙 방식으로 운영하는 것입니다.

이와 같이 [AI 자동화를 통한 확장성]과 [통계 전문 인력의 도메인 검증을 통한 신뢰성]이 상호 보완되는 시스템 아키텍처를 설계한다면, 대규모 국가 통계망 내에서 생성형 AI의 통계 환각 현상을 실무적·구조적으로 안전하게 통제할 수 있을 것으로 사료됩니다.
