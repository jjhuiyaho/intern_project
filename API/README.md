# (1팀) KOSIS 메타데이터 기반 통계 AI 가드레일 도입 제안
> **국가데이터처 청년인턴 정책제안 프로젝트 결과 보고서**

본 저장소는 국가 통계 API 파편화 및 AI 활용 인프라 부족 문제를 해결하고, 현행 대국민 통계 서비스의 신뢰성을 제고하기 위해 수행된 청년인턴 실증 과제물입니다. 

KOSIS 공유서비스에서 제공하는 핵심 지표를 대상으로 비정형 서술형 통계 주석을 기계 판독이 가능한 구조화된 태그로 전환하여, 생성형 AI의 구조적 '맥락맹(Context-Blindness)' 현상과 수치 오독을 제어하는 가드레일 시스템 아키텍처를 실증하였습니다.

---

## 1. 프로젝트 수행 범위 및 한계

본 실증 실험 및 가드레일 구축 작업은 데이터의 중요도와 국민 체감도가 가장 높은 **국가통계포털(KOSIS) '100대 지표' 데이터셋 내부로 범위를 한정하여 수행**되었습니다. 

방대한 국가 통계 전반을 한 번에 다루기보다, 핵심 지표 100개를 집중적으로 분석함으로써 메타데이터 구조화의 실증적 효용성과 프롬프트 미들웨어의 통제 가능성을 보다 정밀하게 검증하고자 하였습니다.

## 4. 데이터 수집 및 파이프라인 구축 방식

본 프로젝트는 KOSIS에서 제공하는 두 가지 핵심 Open API 커넥터를 결합하여 데이터를 가공하였습니다.

1. **정형 수치 수집 (statisticsData):** 지표별 기계어 분류 코드와 통계 수치값을 매핑하여 시스템 콘텍스트의 기본 입력값으로 설정합니다.
2. **비정형 맥락 추출 (statisticsExplData):** 자연어 산문(줄글) 형태로 분리되어 존재하는 '유의사항' 및 '조사연혁' 필드를 파이썬 전처리 엔진으로 호출합니다.
3. **단편적 키워드 기반 태그 변환 (Metadata Assetization):** 파이썬 환경에서 [개편, 단절, 변경, 제외, 잠정] 등의 특정 핵심어를 검출하고, 이를 기계가 해독할 수 있는 고유 위험 태그(warning_tags : [시계열단절], [단순비교금지] 등) 및 논리적 근거(evidence) 구조를 가진 가드레일 JSON 미들웨어 파일로 자산화하였습니다.

## 5. 4대 지표별 3단계 실증 실험 및 비교 결과 요약

> **실험 설계 개요:** 본 실험은 통계 챗봇의 연산 제어 역량을 객관적으로 확인하기 위해 **총 3단계(1단계: 현행 코봇, 2단계: 메타데이터 미적용 상용 AI, 3단계: 구조화 가드레일 적용 AI)**의 대조군으로 설계되었습니다. 특히 AI가 데이터를 잘못 검색하는 검색 오류를 배제하기 위해, 2단계와 3단계 프롬프트 내에 사용자가 정확한 수치를 직접 명시한 후 사칙연산(증감률 비교 등)을 요구하는 통제 환경을 구성했습니다.

### 1) 경기종합지수 (챗봇_실험_결과물/예시_경기종합지수.md)

* **위험 요인:** 기준 개편으로 인한 복합 시계열 단절 및 최근 수치의 잠정치 혼재
* **실험 결과 대조:**
* **2단계 Before (산문형 메타데이터 제공):** 잠정치 경고 문구를 인지하고도 사용자의 연산 요구에 동조하여 단기 경기 반등을 단정 짓는 과잉 해석을 강행하는 한계 노출.
* **3단계 After (가드레일 JSON 주입):** 미들웨어 내 [잠정치포함] 및 [시계열단절] 태그를 인식한 후 연산 요구를 차단하고, 방향성 참고 및 중장기 추세 분석 대안을 출력하여 유의미한 제어 효과 관찰.



### 2) 근로시간 지표 (챗봇_실험_결과물/예시_근로시간.md)

* **위험 요인:** 동일 통계표 내 단위(일·시간·원) 혼재 및 산업분류/규모별 집계 범위 제약
* **실험 결과 대조:**
* **1단계 현행 코봇:** 출처, 조사 대상, 기준이 상이한 3개 기관 조사의 근로시간 수치를 단일 답변 내에 임의 결합하여 정보의 신뢰성 문제 노출.
* **3단계 After (가드레일 JSON 주입):** [항목혼합주의], [단위주의], [분류기준주의] 태그를 선제 판별하여 조건부 계산을 수행하되, "전체근로시간 기준 증가이며 초과근로 증가로 확대 해석 불가"함을 명시하여 해석 범위를 체계적으로 통제하는 안정성 확인.



### 3) 서비스업생산지수 (챗봇_실험_결과물/예시_서비스업생산지수.md)

* **위험 요인:** 기준 지수 개편 및 한국표준산업분류체계(KSIC) 개정이 복합 적용된 고위험 지표
* **실험 결과 대조:**
* **2단계 Before:** 지수 간의 단순 차이를 임의 계산하여 가격 상승 영향이라는 자의적인 분석 문장 생성.
* **3단계 After:** [시계열단절], [기준연도변경], [분류체계변경], [단순비교금지] 태그 스캔 즉시 직접 연산을 차단하고, 공식 보정 시계열(전년동월비 항목)을 별도 인용토록 안내함에 따라 무분별한 수치 오독 방지 기능 관찰.



### 4) 평균 가구원 수 (챗봇_실험_결과물/예시_평균 가구원수.md)

* **위험 요인:** 인구총조사 기반 연간 통계로 연간 공표 최신성 외 특이 제약 없음
* **실험 결과 대조:**
* **1단계 현행 코봇:** 출처 오독(가계동향조사로 오인) 및 존재하지 않는 가구원 수 최대·최소 편차를 가상으로 생성하는 환각 현상 노출.
* **3단계 After:** 고위험 제약 태그가 없음을 자율 검증한 후, 9년간의 가구 규모 축소 추세(-12.0%)를 정량 분석하였으며 분석 전 데이터 생산 주기 특성을 명시하여 절차적 투명성 확보.

## 6. 단계별 종합 비교 및 향후 인프라 확장 제안

### 1) 데이터 연동 단계별 종합 비교

| 평가 항목 | 1단계: 현행 코봇 | 2단계: Before AI (산문형) | 3단계: After AI (구조화 가드레일) |
| --- | --- | --- | --- |
| **출처 및 수치 정확성** | 통계표 매핑 및 데이터 혼합 오류 | 산수는 일치하나 원천 수치 검증 불가 | 분석 전 출처 및 단위 일치 검증 수행 |
| **경고 신호 인지 능력** | 통계 제약 조건 인지 부재 | 자연어 서술 언급에 그침 | 구조화된 기계어 태그 즉각 인식 |
| **위험 감지 후 행동제어** | 환각 및 가상 수치 생성 | 사용자의 연산 요구에 동조 | 연산 기능 차단 및 조건부 허용 전환 |
| **종합 데이터 안전성** | **취약 (신뢰성 저하)** | **유의 요망 (오독 가능성)** | **안정적 (연산 통제 가능)** |

### 2) 현재 파이프라인의 한계성 (단편적 매칭)

본 프로젝트에서 실증한 파이썬 기반 태그 변환 방식은 설명자료 내 특정 단어의 출현 유무에 의존한 '1:1 단편적 키워드 매칭 수준'에 머물러 있습니다. 이는 통계학적 맥락에 대한 심층적 해독이 제한되며, 방대한 KOSIS 전체 체계 내 하위 지표 간의 다층적 위계 및 복잡한 포함 관계(집합 분류 등)를 동적으로 반영하여 검증하기 어렵다는 한계가 존재합니다.

### 3) 향후 정책 발전 방향: '다층적 통계 지식 그래프(Knowledge Graph)' 기반 표준 모델 정립

상기 단편적 매핑의 한계를 보완하고 국가 통계 AI의 활용 인프라를 고도화하기 위해, 향후 국가데이터처의 'AI 친화적 통계 메타데이터 DB 구축 사업' 등 관련 과제 추진 시 **'한국표준산업분류(KSIC)' 등의 기보유 표준 코드 체계를 구조적 뼈대(Ontology)로 활용하는 '다층적 통계 지식 그래프' 인프라 구축을 제안**합니다.

설명자료 API 문서를 LLM이 탐색하여 지식 맵을 자동 형성하고, 상위 도메인 분류의 통계적 제약 조건(가산성 상실, 분류 개편 등)이 하위 지표로 자율 상속(Inheritance)되도록 시스템 아키텍처를 설계한다면, 대규모 국가 통계망 내에서 생성형 AI의 통계 환각 현상을 시스템 레이어에서 구조적으로 통제하는 데 기여할 수 있을 것으로 사료됩니다.
