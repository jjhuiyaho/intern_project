1. 외국인가구 / 다문화가구 / 일반가구
외국인 가구: 외국인으로만 구성된 가구
다문화 가구: 외국인이 한국인과 혼인으로 이루어진 가구 등
단, "한국인과 외국인이 함께 사는 가구는 '일반가구'로 분류
-> 한국인과 외국인이 혼인해서 사는 가구는 '다문화 가구'이면서 통계 집계 상으로는 '일반 가구’

2. 인구
주민등록인구: 거주자+거주불명자+재외국민 (외국인 제외)
장래인구추계: 3개월 이상 상주자 (외국인 포함)
국내인구이동: 주민등록 전입신고자 (외국인 제외)

3. 잠정치·확정치 구분 혼동
출생·사망: 잠정(이듬해 2월), 확정(출생 이듬해 8월 사망 이듬해 9월)
혼인·이혼: 확정(이듬해 3월)

4. 신재생에너지 통계 대상 변경
2009년: 수력을 신재생에너지로 편입, 양수는 별도 분리
2019년: 비재생폐기물(부생가스, 폐기물소각 등)을 신재생에서 기타로 제외
2020년: 수소 분야 추가

5. 이동률
국내인구이동통계의 이동률: 주민등록인구(거주자) 100명당 이동자 수, 월·분기는 연간 수준으로 환산
장래인구추계의 이동률: 인구 100명당 이동자 수, 기준인구가 7월 1일 연앙인구

6. 노령화지수 vs 노년부양비
분자는 고령인구(65세 이상)로 동일 but 분모 다름
노령화지수: 유소년인구(0~14세) 대비
노년부양비: 생산연령인구(15~64세) 대비

7. 장래인구추계 시나리오
중위·고위·저위 추계 시나리오 명시
고위 추계는 출산율·기대수명·국제순이동 모두 최대값, 저위는 최소값

8. 온실가스 총배출량 vs 순배출량
총배출량: LULUCF(토지이용·임업) 제외
순배출량: LULUCF 포함

9. 명칭 변경
신재생에너지 내 우드칩, 성형탄, 임산연료 -> 목재칩, 성형숯, 숯 (since 2025)
