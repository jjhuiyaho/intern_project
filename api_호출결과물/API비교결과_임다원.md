1. 공통 구조
기관 → 통계표 → 분류축 → 항목 → 단위 → 실제값


2. 공통적으로 등장하는 핵심 코드
: 모든 API에서 반복적으로 등장하는 대표 코드들

| 코드          | 의미             |
| ----------- | -------------- |
| `ORG_ID`    | 통계작성기관         |
| `TBL_ID`    | 통계표 ID         |
| `OBJ_ID`    | 분류축(Dimension) |
| `OBJ_NM`    | 분류축 이름         |
| `ITM_ID`    | 항목 코드          |
| `ITM_NM`    | 항목 이름          |
| `UNIT_ID`   | 단위 코드          |
| `UNIT_NM`   | 단위명            |
| `UP_ITM_ID` | 상위 분류 코드       |



3. API 볼때 고려할 포인트
- 숫자만 보면 거의 오해할 수 있음
 
  |   값   |  실제 의미  |
  | ------ | -------    |
  | 83.5   | 기대수명(년)|
  | 0.003  | 사망확률    |
  | 125000 | 등록대수    |
  | 42.1   | 비율(%)     |


-  코드 체계는 통일되어 있지만 의미 체계 다름
  
| API            | 핵심 축(Dimension) |  
| --------       | ---------------    |  
| 이륜차 신고대수 | 지역 × 차종 × 시점  |  
| 생명표         | 연령 × 성별 × 지표   |  
| 사망원인통계    | 사인 × 연령 × 성별   |  
| 1인가구         | 지역 × 성별 × 시점  |


4. 공통적으로 발견되는 구조
- 다차원 통계 구조 : 지역 × 시간 × 항목 × 성별 × 연령 ...
- 계층 구조가 존재 : 전국 -> 시도 -> 시군구 -> ...


5. api 차이점

- 메타데이터 설명 밀도 차이
| 통계     | 특징                |
| ------ | ----------------- |
| 생명표    | 정의·계산식·개정이력 매우 많음 |
| 사망원인통계 | 국제분류·보완조사 설명 포함   |
| 이륜차    | 상대적으로 단순          |
| 1인가구   | 조사방식 변화 설명 중요     |  



- 시계열 단위 차이
| 통계     | 시계열 단위  |
| ------ | ------- |
| 이륜차    | 월       |
| 생명표    | 연       |
| 사망원인통계 | 연       |
| 경제지표   | 월/분기 혼합 |



- 조사방식 차이
| 통계     | 방식      |
| ------ | ------- |
| 이륜차    | 행정등록 집계 |
| 1인가구   | 등록센서스   |
| 생명표    | 추계·가공통계 |
| 사망원인통계 | 신고자료 기반 |


- 통계 개편 이력 확인필요

: 인구총조사는 2015년부터 등록센서스 방식 전환
