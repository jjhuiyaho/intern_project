국가데이터처(AISI) 전략 연계: 통계 특화 AI(MODI) 선행 실증 사업

KOSIS 100대 지표
온톨로지 메타데이터 마스터플랜

본 문서는 현재 시스템의 치명적 한계와 국가데이터처의 비전을 분석하고, 우리가 수집한 원시 API 데이터를 AI가 추론할 수 있는 '정답지(메타데이터)'로 조립 및 실증하는 전체 파이프라인을 정의합니다.

🔙

1. 원래는 어떻게 작동했는가? (기존 시스템의 민낯)

현재 KOSIS 챗봇(코봇)은 데이터를 읽고 분석하는 AI가 아닙니다. 사전에 하드코딩된 질문과 답변을 매칭하는 단순 '링크 안내원'에 불과합니다.

기존 코봇 학습 데이터 (FAQ_815)

"title": "살고싶은 우리동네 링크 연결",
"questions": [
  "살고싶은 우리동네 연결해줘",
  "살고싶은 우리동네 어떻게 들어가?"
]

🚨 치명적 한계:

  • 질문에 특정 수치나 분석을 요구해도 대답할 능력이 0%입니다.
  • 오직 "해당 통계표는 이 URL을 클릭하세요"라며 사용자에게 분석의 책임을 전가합니다.
🎯

2. 현 상황의 문제점과 국가데이터처(AISI)의 정책 방향

현재 직면한 2가지 딜레마

  • 추론의 역설: 기존 챗봇은 안전하지만 멍청합니다. 반대로 챗GPT 같은 LLM에 자유도를 주면, 공식 DB에 접근하지 못해 블로그를 뒤져 가짜 통계(환각)를 퍼뜨립니다.
  • API 맥락맹: KOSIS API(SDMX)는 기계어(`itmId: T30`)로 된 숫자만 줍니다. AI는 그 숫자가 '군인이 제외된 것'인지, '외국인이 포함된 것'인지 몰라 아무 데이터나 섞어버립니다.

국가데이터처의 정책 목표 (Project MODI)

  • Vertical AI 구축: 2027년까지 통계 전문가 수준의 지식을 갖춘 통계청 전용 특화 AI 'MODI'를 구축하는 것이 최종 목표입니다.
  • 의미 개방(Open Meaning): 단순한 숫자(Data) 개방을 넘어, 숫자의 맥락과 제약조건을 AI가 이해할 수 있는 '온톨로지(Ontology) 지식망'으로 전환하는 것이 최우선 과제입니다.
🚀

3. 우리는 이 사업의 어느 부분을 제안하는가? (프로젝트 포지셔닝)

"2027년 MODI를 학습시킬 최초의 시드 데이터(PoC)"

수만 개의 국가 통계를 하루아침에 AI용 메타데이터로 바꾸는 것은 물리적으로 불가능합니다.
따라서 우리 프로젝트는 '대국민 수요가 가장 높은 100대 지표'를 선제적으로 타겟팅합니다.

Step 1. 수작업 매핑 인간 전문가(Human-in-the-loop)가 100대 지표의 복잡한 API 구조와 통계 설명서를 직접 해체합니다.
Step 2. 템플릿(SOP) 정립 기계어(SDMX)를 AI 친화적 자연어 프롬프트로 번역하는 '표준 변환 공식'을 국내 최초로 정립합니다.
Step 3. 반자동화 확장 제안 우리가 만든 100개의 정답지를 AI(LLM)에 먹여, 나머지 수만 개 지표를 자동 매핑하게 만드는 확장 파이프라인을 제안합니다.
🛠️

4. 실무 가이드: 수집한 데이터를 어떻게 조립해야 하는가?

팀원들이 뽑아온 복잡한 JSON 파일(API 탐색 결과)과 코봇 용어사전에서 딱 3가지(좌표, 분모, 가드레일)만 캐내어, AI의 뇌를 통제할 단 하나의 '명령문(System Prompt)'으로 융합 조립합니다.

1

좌표 따오기 (팩트)

출처: API결과.json ➡️ 2_메타자료(ITM)

"ITM_NM": "전체", "ITM_ID": "T30"
추출 결과: tblId: DT_1DA7001S / itmId: T30
👉 AI가 가짜뉴스를 만들지 않고 실시간으로 숫자를 긁어올 '절대 좌표'입니다.
2

분모 찾기 (맥락 부여)

출처: API결과.json ➡️ 1_통계설명

"examinObjrange": "...군인, 수감자 제외"
추출 결과: 본 수치에 군인과 사회복무요원이 제외됨.
👉 AI가 이 데이터를 다른 인구 통계랑 함부로 섞지 못하게 하는 '맥락(Context)'입니다.
3

가드레일 (의도 충돌 방지)

출처: KOSIS_3_용어사전.json

"term": "청년실업률", "description": "15-29세 기준"
추출 결과: 사용자가 '청년실업률'을 물을 경우 전체와 섞지 말고 15-29세로 한정.
👉 유사한 단어 때문에 AI가 엉뚱한 지표를 가져오는 '의도 충돌'을 막아줍니다.

✨ [최종 조립 결과] AI 시스템 지시문 (System Prompt)

"사용자가 '실업률'을 질의하면 [itmId: T30]을 호출하라. 단, '청년실업률'을 특정하면 전체와 혼용하지 말고 15-29세에 해당하는 [itmId: T31]을 호출할 것. 브리핑 작성 시 해당 데이터는 군인 및 사회복무요원이 제외된 수치임을 서론에 명시하여 데이터 임의 결합(환각)을 방지하라."
📊

5. 최종 증명: 어떻게 만들어서, 어디에 활용해, 무엇을 보여주는가?

팀원들이 만든 100개의 지표 정답지는 단 하나의 시스템 JSON 스키마 파일(KOSIS_100_Ontology_Master.json)로 취합됩니다. 이 완성된 파일을 활용하여 우리는 정책 입안자들에게 다음 3가지의 강력한 실증 결과(PoC)를 증명해야 합니다.

📍 5-1. 어디에, 어떻게 활용되는가? (시스템 이식 파이프라인)

우리가 만든 JSON 파일은 단순히 문서를 넘어, 2027년 도입될 통계 특화 AI(MODI)의 '사전 필터링 두뇌(Vector DB)'로 직접 이식됩니다. LLM이 대답을 지어내기 전에 반드시 이 지식망을 통과하도록 설계됩니다.

1. 사용자 질의 입력
➡️
2. 우리가 만든 메타데이터 강제 주입
(좌표 검색 + 한계점/가드레일 프롬프트 패키징)
➡️
3. LLM의 안전한 답변 생성

📍 5-2. 무엇을 보여줄 것인가? (3대 실증 과제)

① 환각 0% A/B 테스트

메타데이터의 유무에 따른 AI의 답변 품질 차이를 실제 비교 화면(Mock-up)으로 시연하여 정책 결정자를 설득합니다.

Q. "우리나라 1인 가구 수치가 어떻게 돼?"
❌ 기존 AI (우리 데이터 없음)
블로그를 검색하여 부정확한 수치를 나열함. 해당 수치에 내/외국인이 포함되었는지 설명하지 못함. (맥락맹)
✅ 적용 AI (우리 데이터 주입)
"1인 가구는 N만 명입니다. 단, 이 수치는 내국인뿐만 아니라 외국인까지 포함된 총량 기준임을 유의하시기 바랍니다." (정확한 좌표 + 분모 고지)

② 설명 가능한 AI (XAI) 시연

단순히 숫자를 뱉는 기계가 아니라, 데이터의 출처와 비교/결합 시 한계점을 스스로 설명하는 전문가적 능력을 증명합니다.

우리가 [가드레일]에 작성해 둔 통계 용어사전의 정의(예: 사업체와 기업체의 차이, 2016년 산출방식 갱신 이력)가 챗봇의 브리핑 하단에 '💡 통계 분석 유의사항'이라는 코너로 자동 생성됨을 보여줍니다. 이를 통해 AI가 이종 데이터 간의 무분별한 결합을 막아냄을 증명합니다.

③ 수만 개 지표로의 확장성

수작업의 한계를 비판하는 현업 부서에게, AI 자동화(Auto-Labeling)를 위한 마중물임을 증명합니다.

"저희가 수작업으로 완벽하게 다듬은 이 100개의 정답지(SOP)를 강력한 LLM에게 '학습 교과서(Few-shot Data)'로 먹이면, 나머지 1,000개의 통계 API는 AI가 이 패턴을 모방하여 반자동(Semi-automated)으로 온톨로지 매핑을 수행할 수 있습니다."라는 확장 로드맵을 최종적으로 제시합니다.
